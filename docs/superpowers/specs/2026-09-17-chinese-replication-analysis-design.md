# SOCRATES 中文复现实验分析设计

**日期：** 2026-09-17  
**状态：** 用户已批准设计方向，等待书面规格复核  
**目标数据：** `results/replication_zh_2026-09-18/results_local_zh_2026-09-18.csv`

## 1. 目标

使用 SOCRATES 原分析方法，对新完成的六个开源模型中文实验进行完整分析，并产出两套彼此区分的结果：

1. 六个中文模型的独立复现分析；
2. 六个中文模型与中文人类数据的语言匹配对照。

新分析必须保留旧论文结果，所有新表格、图像和报告均写入复现实验自己的目录。分析只支持行为层面的置信度校准与元认知相关特征，不把 M-ratio 或 verbalized confidence 解释为模型具有意识或内部元认知机制的直接证据。

## 2. 非目标

- 不覆盖 `experiment/results/analysis/`、`experiment/results/figures/` 或旧版 `master_long.csv`。
- 不修改题库、提示词、模型原始回答或人工受试数据。
- 不把中文结果与旧英文模型结果混入同一主表后直接作无条件排名。
- 不更新论文、README、PPT、海报或公开仓库；这些需要在分析完成并经用户复核后另行决定。
- 不运行新的模型推理。

## 3. 输入与纳入规则

### 3.1 模型数据

主输入为：

`results/replication_zh_2026-09-18/results_local_zh_2026-09-18.csv`

预期包含 9,600 个唯一任务键：六个模型 × 400 道题 × 每题四次独立采样。唯一键为：

`model × language × item_id × sample_idx`

仅 `parse_ok == True` 且答案、金标准和 1–5 置信度均有效的记录进入指标计算。无效记录不删除，单独计入覆盖率与失败原因表。

### 3.2 人类数据

从 `experiment/results/master_long.csv` 读取：

- `model == "human"`
- `language == "zh"`
- `status == "ok"`
- 答案、金标准和置信度字段有效

当前文件检查显示共有 46 名参与者、1,647 条有效中文回答。任何公开或汇总产物都不得包含参与者标识或逐人数据。

### 3.3 分析数据集

- **模型独立集：** 六个中文模型的有效记录。
- **语言匹配对照集：** 中文人类有效记录加六个中文模型有效记录。

人类与模型的采样结构不同：人类每人回答题目子集，模型每题独立采样四次。因此不把所有 trial 当作相互独立；区间估计必须采用不同的聚类单位。

## 4. 分析方法

沿用原 SOCRATES 定义：

- 判断题机会水平为 0.5。
- 五档置信度映射为 `0.50, 0.625, 0.75, 0.875, 1.00`。
- Accuracy：正确回答比例。
- Mean confidence：原始 1–5 置信度均值。
- Overconfidence：映射后平均置信度减准确率。
- ECE：按五档置信度分箱的加权绝对校准误差。
- Type-2 AUROC：置信度区分正确与错误回答的能力。
- meta-d′ 与 M-ratio：使用与旧分析一致的 Maniscalco–Lau MLE 实现。

### 4.1 分层分析

分别按以下维度汇总准确率、置信度、过度自信与样本数：

- 题型：常规、学科、陷阱、幻觉；
- 难度：易、中、难；
- 置信度档位：1–5；
- 幻觉题金标准：虚构实体 `False` 与真实冷僻实体 `True`。

### 4.2 不确定性估计

- 人类：按 `participant_id` 聚类 bootstrap。
- 模型：按 `item_id` 聚类 bootstrap，保持同一题四次采样的相关结构。
- 主要区间：95% percentile bootstrap CI。
- Bayesian HMeta-d 作为辅助估计，不替代主要 MLE 结果。

### 4.3 M-ratio 证据等级

按每组错误 trial 数标注：

- `data-driven`：至少 30 个错误；
- `regularized`：10–29 个错误；
- `prior-dominated`：少于 10 个错误。

MLE 数值可以保留用于透明性，但 `regularized` 组主要参考 Bayesian 辅助估计；`prior-dominated` 组不据此下元认知强弱结论。近满分模型的 M-ratio 不稳定性必须在表格和报告中明确提示。

## 5. 实现结构

采用独立分析入口，不改写旧分析的默认输入或输出。

### 5.1 分析入口

新增一个中文复现分析脚本，职责包括：

1. 读取并验证两类输入；
2. 标准化列类型与状态；
3. 生成描述统计和分层统计；
4. 调用或复用原项目的 ECE、type-2 AUROC、meta-d′/M-ratio 计算逻辑；
5. 执行聚类 bootstrap；
6. 保存机器可读表格和中文摘要。

若 Bayesian HMeta-d 需要独立长时间运行，则使用同一清洗数据和同一输出目录，生成可恢复、可重复执行的分组结果，最后由汇总步骤合并。

### 5.2 输出目录

所有产物写入：

`results/replication_zh_2026-09-18/analysis/`

计划输出：

- `data_quality.csv`：每组原始数、有效数、失败数、覆盖率与失败原因；
- `model_summary.csv`：六模型核心指标；
- `human_model_summary.csv`：中文人类与六模型对照；
- `by_type.csv`：按题型结果；
- `by_difficulty.csv`：按难度结果；
- `confidence_distribution.csv`：五档置信度分布；
- `reliability.csv`：校准曲线数据；
- `hallucination_breakdown.csv`：虚构与真实冷僻题分解；
- `metad_summary.csv`：d′、meta-d′、M-ratio 与证据等级；
- `bootstrap_summary.csv`：主要指标的聚类 bootstrap CI；
- `hmetad_summary.csv`：Bayesian 辅助估计及诊断；
- `tables.md`：便于论文和 README 引用的 Markdown 表格；
- `analysis_report_zh.md`：结果、解释、限制和下一步建议。

图像写入 `analysis/figures/`，至少包括：

- 六模型准确率与 ECE；
- 中文人类与六模型的准确率/ECE 对照；
- 按题型准确率；
- M-ratio 与证据等级；
- 可靠性曲线；
- 幻觉题虚构/真实冷僻分解。

## 6. 数据流与可恢复性

原始 CSV 和人类主表保持只读。脚本先完成输入审计，再生成清洗后的内存数据集，不另存包含参与者标识的公开中间文件。每个输出使用确定性排序；bootstrap 使用记录在报告中的固定随机种子。

Bayesian 分组运行可以重复执行：已有且通过诊断的模型结果默认复用，失败或未完成的分组可以单独重跑。最终报告只有在所有必需的非 Bayesian 表格生成且验证通过后才标记为完成；Bayesian 失败时必须明确标记为未完成，不能静默缺失。

## 7. 校验与测试

分析开始前验证：

- 模型文件总计 9,600 行；
- 任务唯一键总计 9,600 个，无重复；
- 每个模型恰有 1,600 个任务；
- 语言均为中文；
- 人类汇总不包含于模型独立表；
- 无效任务仅从指标分母排除，不从质量表消失。

分析完成后验证：

- 所有预定 CSV、Markdown 和图像存在且非空；
- 汇总表中的 `n_valid + n_invalid == n_attempted`；
- 每组 Accuracy 与原始正确数能够反算一致；
- ECE 在 `[0, 1]` 的理论范围内；
- bootstrap 区间包含对应点估计或报告偏差原因；
- M-ratio 证据等级与错误数阈值一致；
- 人类聚类单位为参与者、模型聚类单位为题目；
- 图表标签、模型顺序和表格数据一致；
- 旧分析目录的文件内容与运行前一致。

## 8. 解释边界

报告可回答：

- 六个中文开源模型的准确率和校准表现如何；
- 模型规模变化是否伴随准确率、ECE 或置信度分辨能力变化；
- 在同一中文题目和置信度格式下，人类与模型的行为差异如何；
- 哪些模型有足够错误支持 data-driven 的 M-ratio 估计；
- 幻觉题上的错误模式是否与旧英文结果一致。

报告不能据此断言模型拥有意识、主观体验或内部元认知模块。跨模型规模趋势属于观察性比较，量化方式、训练数据、架构和模型家族同时变化时，不作单一因果解释。

## 9. 完成标准

任务在以下条件同时满足时完成：

1. 两套分析表均生成并通过自动校验；
2. MLE、聚类 bootstrap 和 Bayesian 辅助分析有明确完成状态；
3. 主要图像与表格数值一致；
4. 中文报告区分事实结果、统计不确定性和解释边界；
5. 旧分析产物未被覆盖；
6. 用户可以直接打开输出目录检查并决定是否更新论文或 README。
